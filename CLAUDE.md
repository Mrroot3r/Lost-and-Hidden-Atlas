# Lost & Hidden Atlas: instructions for AI models

Read `GUIDE.md` before doing anything. The short version:

- The files in the repository root (`index.html`, `app.js`, `sw.js`, `data/`, `topo/`) are **build output**. Edit `source/` and rebuild with the commands in GUIDE.md section 3.
- When adding places, follow the research rules in GUIDE.md section 5: every fact from a source you opened, no filling gaps from memory, honest pin precision with a pin note, access stated, nothing that tells anyone how to get into a building or past a fence.
- Never rename a place `id`. Never commit personal information; the repository is public.
- Run the smoke test before pushing. Pushing to `main` publishes the site.
- The owner uses the Atlas on an Android phone in the field. Test at phone size first.
